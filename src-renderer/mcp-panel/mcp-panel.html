无法连接 MCP 监控面板

TurboWarp Desktop 无法访问 MCP 服务器的监控页面。请确认服务器已启动，并且端口与下面显示的地址一致。

面板地址
—
错误信息
—

启动带 HTTP 传输的 MCP 服务器（推荐，同时提供 /dashboard）：

node dist/index.js --http --port 3000

或者，在 stdio 模式下只启动监控面板：

node dist/index.js --dashboard-port 3000

如果服务器使用其他端口，请在启动 TurboWarp Desktop 前设置环境变量 TW_MCP_DASHBOARD_URL，例如 http://127.0.0.1:3210/dashboard。
